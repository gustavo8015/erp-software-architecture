# 10. Glosario

| Término | Definición |
|---|---|
| **Producto** | Bien o insumo que la empresa adquiere y mantiene en su catálogo, identificado por nombre, descripción y unidad de medida. |
| **Proveedor** | Persona o empresa (con NIT) que suministra productos a la organización. |
| **Orden de Compra** | Documento formal emitido a un proveedor con los productos, cantidades y precios acordados; estados: Emitida, Recibida parcial, Recibida total, Anulada. |
| **Recepción de Mercancía** | Registro de la entrada física de productos asociada a una orden de compra; actualiza el stock. |
| **Stock** | Cantidad disponible de cada producto en el inventario. |
| **MoSCoW** | Técnica de priorización: Must have, Should have, Could have, Won't have. |
| **Épica** | Historia de usuario de gran tamaño que agrupa historias más pequeñas (aquí, un módulo del ERP). |
| **C4** | Modelo de diagramas de arquitectura por niveles: Contexto (C1), Contenedores (C2), Componentes (C3), Código (C4). |
| **arc42** | Plantilla estándar de 12 secciones para documentar arquitecturas de software. |
| **EIS** | Executive Information System: módulo de indicadores y reportes para la dirección. |
| **SPA** | Single-Page Application: aplicación web que corre en el navegador y consume una API. |
